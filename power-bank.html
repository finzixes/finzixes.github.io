Power Bank That's Not a Power Bank

Home Resume Running Projects Photos

An EE 221 final project built with Kristopher Schmit exploring voltage regulation, USB charging behavior, circuit implementation, and the limitations of linear voltage regulators.

Despite the name, it is not actually a power bank. It currently requires an external power supply.

Goal

Build a simple USB power supply using an LM7805 voltage regulator to reduce a higher input voltage to approximately 5V for USB-powered devices.

What We Explored

  • LM7805 linear voltage regulation
  • Heat dissipation and regulator efficiency
  • USB charging behavior
  • Shorting the USB data pins for charging detection
  • LED power indication
  • Breadboard implementation and testing
  • Voltage and current measurements
  • Possible improvements using a buck converter
